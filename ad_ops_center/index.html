Lab 2: Continuous Loops & Reflection

Audit execution traces on GEAP and implement self-correcting SQL feedback.

6 Steps
1

Evolve to Continuous Loops

In this lab, we automate the agent execution. Wrap your `yield_agent.py` script inside a continuous executor loop `run_optimizer.py` that runs every 60 seconds.

Verification Tasks
  1. Write `run_optimizer.py` importing `yield_agent` inside a `while True` sleep loop.
  2. Start your continuous loop agent locally:
    3. python run_optimizer.py
  3. Wait for the agent to execute a couple of optimization cycles.
2

Deploy to Google Enterprise Agent Platform

Deploy your loop agent to GEAP to run it in a secure cloud environment linked with BigQuery IAM permissions.

Deployment Commands 
# 1. Package and deploy agent
agent-platform deploy yield-agent --source .

# 2. Verify cloud hosted URL
agent-platform describe yield-agent
3

Trigger Competitor Dropout & Observe Bid Inflation

Now, simulate a market event: competitor campaigns drop out of the market. Let's see if your stateless loop agent responds appropriately:

Simulation Results (Stateless Loop) 100% Win-Rate
Total Auctions: 20
Wins: 20
Active Bid CPM: $8.05
Competitor P90 range: $1.50
**Warning: Bid Inflation Detected!** Your campaign won all auctions, but you are bidding $8.05 while the highest competitor is only bidding $1.50. Because the agent is stateless, it has no memory of its own past actions and continues to overpay, wasting your campaign budget.
4

Audit Execution Traces in GEAP Console

Open the platform cloud console to inspect the trace of the loops to identify the exact cause of this runaway bidding behavior.

Trace Auditing Steps
  1. Open the Google Cloud Console and navigate to the **Enterprise Agent Platform** section.
  2. Select your deployed `yield-agent` and navigate to the **Trace Logs** tab.
  3. Examine the prompt traces for the last few runs: note that the agent receives no context about its previous bids, current win rates, or budget depletion speed.
5

Implement Self-Correcting SQL Feedback

Add history-reflection to your agent. Implement the `get_agent_decision_history` query tool querying the `auction_events` table for your own previous bid performance metrics.

Implementation Task

Equip your agent with the history tool, update the system instructions to analyze previous clearance prices, and adjust your bids down by 10% on high-win cycles until you clear the market clearance CPM. 

# Run your updated agent locally
python yield_agent.py
6

Verify stabilized CPM clearance

Let's run the simulation cycle again with your self-correcting agent loop active:

Simulation Results (Reflective Loop) 85% Win-Rate
Total Auctions: 20
Wins: 17
Active Bid CPM: $1.60
Competitor P90 range: $1.50
**Success! Feedback Loop Active.** The agent successfully analyzed its history, saw that a lower bid would still win auctions, and stepped the bid CPM down to the cleared clearance range ($1.60), saving 80% of campaign budget while keeping high win rates.
